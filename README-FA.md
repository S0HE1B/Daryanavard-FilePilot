# Daryanavard-FilePilot

**یک دستیار هوش مصنوعی محلی برای مدیریت هوشمند فایل‌ها و بهینه‌سازی سیستم.**

Daryanavard-FilePilot یک برنامه دسکتاپ متن‌باز است که به کاربران کمک می‌کند فایل‌های خود را با استفاده از دستورات طبیعی پیدا، مرتب، تحلیل و مدیریت کنند و در کنار آن ابزارهایی برای مانیتورینگ و بهینه‌سازی سیستم ارائه می‌دهد.

**اطلاعات و فایل‌های شما روی دستگاه خودتان باقی می‌مانند.**

## ✨ امکانات

### 🤖 دستیار هوشمند فایل

* جستجوی فایل با زبان طبیعی
* پیدا کردن عکس‌ها، اسناد، ویدیوها و سایر فایل‌ها
* ایندکس کردن فایل‌ها به‌صورت محلی
* جستجوی سریع

### 📁 مدیریت هوشمند فایل‌ها

* پیشنهاد مرتب‌سازی فایل‌ها
* پیدا کردن فایل‌های تکراری
* پیدا کردن فایل‌های حجیم
* تحلیل فضای ذخیره‌سازی
* تغییر نام هوشمند فایل‌ها
* دسته‌بندی فایل‌ها
* پیشنهاد پاکسازی امن
* باز کردن مستقیم محل فایل

### 🧹 پاکسازی فایل‌های تکراری

برنامه می‌تواند فایل‌های یکسان یا تکراری را پیدا کند و قبل از هر اقدامی آن‌ها را به کاربر نشان دهد.

هیچ فایل مهمی نباید بدون تأیید کاربر به‌صورت دائمی حذف شود.

### 📊 مانیتورینگ سیستم

نمایش اطلاعات سیستم به‌صورت لحظه‌ای:

* میزان مصرف CPU
* میزان مصرف RAM
* میزان مصرف GPU
* میزان مصرف VRAM در صورت پشتیبانی سیستم
* دمای سیستم در صورت در دسترس بودن
* آمار منابع سیستم

### 🧠 بهینه‌سازی حافظه

برنامه میزان مصرف حافظه را بررسی کرده و گزینه‌های امنی برای بهینه‌سازی ارائه می‌کند.

FilePilot نباید به‌صورت کورکورانه پردازش‌های سیستمی را متوقف کند. عملیات حساس باید با تأیید کاربر انجام شوند.

### 🎮 حالت Performance

یک حالت مخصوص بازی و کارهای سنگین.

این حالت می‌تواند فعالیت‌های غیرضروری پس‌زمینه را کاهش داده و تنظیمات قابل‌دسترس سیستم را برای عملکرد بهتر بهینه کند.

### 🖥️ ویجت دسکتاپ

یک ویجت کوچک و شناور روی دسکتاپ می‌تواند اطلاعات زیر را نمایش دهد:

* مصرف CPU
* مصرف RAM
* مصرف GPU
* اطلاعات سیستم
* کنترل‌های بهینه‌سازی حافظه

ویجت می‌تواند در پس‌زمینه اجرا شود بدون اینکه پنجره اصلی برنامه باز باشد.

### 🚀 اجرای خودکار

امکان اجرای خودکار برنامه هنگام روشن شدن سیستم.

در صورت فعال بودن، FilePilot می‌تواند در پس‌زمینه اجرا شود و به‌جای باز کردن پنجره اصلی، ویجت دسکتاپ را نمایش دهد.

### 🌙 رابط کاربری مدرن

* رابط کاربری مدرن و زیبا
* حالت تاریک
* حالت روشن
* زبان انگلیسی
* زبان فارسی
* پشتیبانی کامل از RTL

## 🔐 حریم خصوصی در اولویت

حریم خصوصی یکی از اصول اصلی Daryanavard-FilePilot است.

معماری برنامه بر پایه Local-First طراحی شده است:

* فایل‌های شما روی کامپیوتر خودتان باقی می‌مانند
* نیاز اجباری به حساب ابری وجود ندارد
* نیاز اجباری به API پولی هوش مصنوعی وجود ندارد
* آپلود اجباری فایل‌ها وجود ندارد
* ذخیره‌سازی اطلاعات به‌صورت محلی
* پردازش محلی در قابلیت‌هایی که از آن پشتیبانی می‌کنند
