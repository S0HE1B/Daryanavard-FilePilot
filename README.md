# Daryanavard-FilePilot

**A privacy-first local AI assistant for intelligent file management and system optimization.**

Daryanavard-FilePilot is an open-source desktop application designed to help users find, organize, analyze, and manage their files using natural-language commands, while also providing system monitoring and performance tools.

Your data stays on your device.

## ✨ Features

### 🤖 AI File Assistant

* Natural-language file search
* Find images, documents, videos, and other files using simple commands
* Local file indexing
* Fast file search

### 📁 Smart File Management

* File organization suggestions
* Duplicate file detection
* Large file finder
* Storage analyzer
* Smart file renaming
* File categorization
* Safe cleanup suggestions
* Open file location directly

### 🧹 Duplicate Cleaner

Find identical or duplicate files and review them before taking action.

Files are never permanently deleted without user confirmation.

### 📊 System Monitor

Monitor your computer in real time:

* CPU usage
* RAM usage
* GPU usage
* VRAM usage when available
* Temperature information when supported
* System resource statistics

### 🧠 Memory Optimization

Analyze memory usage and provide safe optimization options.

The application does not blindly terminate system processes. Potentially unsafe actions require user confirmation.

### 🎮 Performance Mode

A dedicated mode for gaming and heavy workloads.

It can help reduce unnecessary background activity and optimize available system settings for better performance.

### 🖥️ Desktop Mini Widget

A lightweight floating widget can display:

* CPU usage
* RAM usage
* GPU usage
* System information
* Memory optimization controls

The widget can run in the background without keeping the main application window open.

### 🚀 Startup

Optional automatic startup with the operating system.

When enabled, FilePilot can start in the background and display the desktop widget instead of opening the main window.

### 🌙 Modern UI

* Modern desktop interface
* Dark mode
* Light mode
* English
* Persian / Farsi
* Full RTL support for Persian

## 🔐 Privacy First

Privacy is one of the core principles of Daryanavard-FilePilot.

The application is designed around a local-first architecture:

* Your files remain on your computer
* No mandatory cloud account
* No paid AI API required
* No mandatory file uploads
* Local data storage
* Local processing whenever supported

## 💻 Installation

Installing Daryanavard-FilePilot is simple.

1. Download the latest installer from the [Releases](../../releases) page.
2. Run the installer.
3. Choose the folder where you want to install Daryanavard-FilePilot.
4. Click **Install**.
5. The installer will automatically install and configure the application.
6. Launch Daryanavard-FilePilot and start using it.

No manual configuration is required.

### 🚀 First Launch

After installation, open Daryanavard-FilePilot.

On the first launch, the application will guide you through the initial setup, including selecting folders that you want FilePilot to index.

> **Note:** The application does not require a separate server or manual backend setup.
